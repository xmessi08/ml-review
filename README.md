# Machine Learning Review

Учебный проект по основам машинного обучения (Machine Learning). В проекте рассматривается задача классификации опухолей молочной железы с использованием нескольких алгоритмов машинного обучения.

Проект предназначен для начинающих, которые хотят понять основные этапы работы с Machine Learning: от изучения данных до обучения моделей, оценки их качества и изменения порога классификации.

---

## 1. О проекте

**Machine Learning Review** — это практический проект, в котором мы изучаем и сравниваем алгоритмы машинного обучения на реальном наборе данных.

Главная задача проекта — научиться определять, является ли опухоль:

- **Malignant (0)** — злокачественной;
- **Benign (1)** — доброкачественной.

Для решения этой задачи используется обучение с учителем (Supervised Learning), а именно классификация (Classification).

### Цели проекта

1. Познакомиться с набором данных.
2. Провести исследовательский анализ данных (EDA).
3. Разделить данные на обучающую и тестовую выборки.
4. Подготовить данные для обучения.
5. Обучить несколько моделей машинного обучения.
6. Сравнить результаты разных алгоритмов.
7. Изучить влияние порога классификации (Threshold).
8. Научиться правильно оценивать качество моделей.

## 2. Используемый набор данных

В проекте используется **Breast Cancer Wisconsin Dataset** из библиотеки Scikit-learn.

Набор данных содержит информацию о характеристиках опухолей молочной железы.

Основная информация:

| Характеристика | Значение |
|---|---:|
| Количество объектов | 569 |
| Количество признаков | 30 |
| Количество целевых классов | 2 |
| Количество доброкачественных случаев | 357 |
| Количество злокачественных случаев | 212 |
| Пропущенные значения | 0 |

### Что такое признаки (Features)?

Признаки — это характеристики объектов, которые используются моделью для обучения и предсказания.

В данном проекте используются, например:

- `mean radius` — средний радиус;
- `mean texture` — средняя текстура;
- `mean perimeter` — средний периметр;
- `mean area` — средняя площадь;
- `mean smoothness` — средняя гладкость.

### Что такое целевая переменная (Target)?

Target — это значение, которое модель должна научиться предсказывать.

В нашем проекте:

- `0` — Malignant (злокачественная опухоль);
- `1` — Benign (доброкачественная опухоль).

## 6. Основные этапы Machine Learning

### Этап 1. EDA — Exploratory Data Analysis

EDA — это исследовательский анализ данных.

На этом этапе мы изучаем структуру набора данных, количество объектов, признаки, пропущенные значения и распределение классов.

В нашем проекте было обнаружено:

- 569 объектов;
- 30 признаков;
- 2 целевых класса;
- 0 пропущенных значений.

EDA помогает понять данные до начала обучения модели.

### Этап 2. Train/Test Split

Перед обучением данные необходимо разделить на две части.

**Train (обучающая выборка)** — данные, на которых модель обучается.

**Test (тестовая выборка)** — данные, на которых проверяется качество обученной модели.

Зачем это нужно?

Если проверять модель только на тех данных, на которых она обучалась, нельзя объективно оценить, насколько хорошо она будет работать с новыми данными.

### Этап 3. Обучение моделей

В сохранённых результатах проекта представлены следующие алгоритмы:

| Алгоритм | Описание |
|---|---|
| Logistic Regression | Логистическая регрессия для классификации |
| k-Nearest Neighbors (kNN) | Метод ближайших соседей |
| Decision Tree | Дерево решений |
| Random Forest | Ансамбль деревьев решений |
| Boosting | Последовательное улучшение моделей |

Каждый алгоритм использует свой подход к поиску закономерностей в данных.

### Этап 4. Сравнение моделей

Для оценки качества классификации используются метрики:

**Accuracy** — доля правильных предсказаний среди всех предсказаний.

**Precision** — доля правильных положительных предсказаний среди всех предсказаний положительного класса.

**Recall** — доля найденных положительных объектов среди всех действительно положительных объектов.

**F1-score** — гармоническое среднее Precision и Recall.

В сохранённом результате сравнения моделей получены следующие значения:

| Модель | Accuracy Train | Accuracy Test | Recall |
|---|---:|---:|---:|
| Logistic Regression | 0.988 | 0.965 | 0.925 |
| kNN | 0.977 | 0.958 | 0.906 |
| Decision Tree | 1.000 | 0.958 | 0.906 |
| Random Forest | 1.000 | 0.958 | 0.887 |
| Boosting | 1.000 | 0.965 | 0.906 |

На основании сохранённых результатов Logistic Regression и Boosting показали наибольшую Accuracy Test — 96.5%.

Однако для окончательного выбора модели необходимо учитывать не только Accuracy, но и Recall, Precision, а также то, какой класс считается положительным.

**Важно:** в этом наборе данных класс `0` означает злокачественную опухоль, а класс `1` — доброкачественную. При стандартном расчёте Recall в Scikit-learn положительным считается класс `1`. Поэтому для медицинской задачи необходимо отдельно проверять Recall класса `0`, чтобы оценить, насколько хорошо модель находит злокачественные опухоли.

### Этап 5. Threshold — порог классификации

Threshold — это порог вероятности, по которому модель принимает решение о принадлежности объекта к классу.

Например, если модель предсказывает вероятность 0.7, а установленный порог равен 0.5, объект относится к положительному классу.

В проекте исследуется влияние разных порогов:

| Threshold | TP | FN | FP | TN | Precision | Recall |
|---|---:|---:|---:|---:|---:|---:|
| 0.5 | 49 | 4 | 1 | 89 | 0.980 | 0.925 |
| 0.3 | 51 | 2 | 1 | 89 | 0.981 | 0.962 |
| 0.1 | 52 | 1 | 6 | 84 | 0.897 | 0.981 |

При снижении порога Recall в приведённом эксперименте увеличивается, но Precision уменьшается.

Это показывает, что изменение порога влияет на количество ошибок модели.
